# Contributing AI tools

Suggest a tool by opening an issue or pull request. Include these four details:

```text
Title: Tool name
Description: One or two sentences explaining what the tool does and who it helps.
Link: https://example.com/official-tool-page
Main category: One category from the list below
```

Choose the **main category** that best fits the tool's primary use:

- AI API tools
- AI design tools
- AI coding tools
- AI security assessment tools
- AI social media manager tools
- AI Google Ads tools

Use the tool's official website or product page for the link. Check the existing entries in [README.md](README.md) before suggesting a duplicate. If you open a pull request, add the tool to the matching category table with a short usage description and its official link.
